Losshound v0.1.4 improves live diagnostics, stability, and everyday usability.

### Highlights

- Live Drop Analyzer readings, sample counts, and countdowns, with safer Stop and shutdown handling.
- Refreshed Score, Optimizer, WiFi, History, and Routes pages, plus simpler navigation and clearer empty states.
- Cleaner monitoring controls and a fix for clipped Resume button text.
- Optimization previews that explain proposed changes before applying them.
- Hardened Windows command execution and LAN requests, with improved webhook log redaction.
- Windows CI with dependency advisory checks, automated tests, executable packaging, and startup checks.

### Download

Download **Losshound.exe** for Windows x64. It is portable and does not require a separate Python installation. **Losshound.exe.sha256** contains its SHA-256 checksum.

This build is unsigned, so Windows may warn about or block it. A matching checksum confirms file integrity; it does not establish publisher trust.
